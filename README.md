### 01 — Disaster Recovery | November 2026

**Восстановление production-инфраструктуры после кибератаки на хостинг-провайдера.**

Реальный проект, в котором я участвовал в восстановлении веб-приложения после масштабного инфраструктурного сбоя.

**Что было сделано:**
- Диагностика сетевых проблем и SSH.
- Миграция на новый VPS.
- Настройка Ubuntu Server и Nginx.
- Восстановление PostgreSQL и проверка резервных копий.
- Настройка DNS, HTTPS и HTTP/2.
- Восстановление бронирований и платёжной интеграции.

**Результат:** production-сервис восстановлен, сайт работает, первая реальная оплата успешно прошла.
